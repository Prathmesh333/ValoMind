seconds. Recorded ten visible roster entries per frame, including portrait-based
character labels, scoreboard teams and the CURRENT map label. Added round, score,
timer and planted-spike-icon notes separately. Evidence images and CSVs are under
results/manual_comparison. This is a targeted audit of the first two minutes, not
a review of the entire 56-minute highlight compilation.

These assistant visual annotations remain proposed. The assistant previously saw
the pipeline results and seeded labels, so this is not a blinded or independent
ground-truth evaluation. No canonical event verification status is changed.

No mismatched nonempty fields or extra pipeline rows were found in this selected
sample. This is not a claim of full-video precision or accuracy. The six frames
were selected to include both layouts, deaths, missing team OCR and a missed name.

The missing entry is Jamppi at 28.028s. The name is readable in the source; OCR
confidence .4498 is below the parser threshold. At 86.086s, both team names are
visually readable but OCR/alias thresholds leave all ten team fields unknown.
Those are extraction omissions, not wrong team predictions. Character fields are
empty because the pipeline has no trained portrait classifier. The table's visual
character labels were not generated by YOLO and were not inserted into its output.

The scoreboard shows round 1 at 0–0 on the first three frames, and round 3 at
100T 2–0 VIT on the last three. At 114.114s, a planted-spike icon replaces the timer;
the timer reference is blank rather than inferred. These context fields are not
implemented in the current roster parser and are not included in its match counts.

## Recommended correction order

1. Retry OCR on tightly cropped name/team regions for missing fields, retaining
   the original evidence and confidence. Do not globally lower confidence gates.
2. Use reviewed portrait examples to train/validate a small character classifier,
   including grayscale/dead and unknown cases. Never assign a character from a
   player's usual pick or name.
3. Evaluate the segment gate on labeled uncertain/filler/replay samples; this
   comparison only covers admitted gameplay frames and cannot measure gate recall.
4. Validate on another broadcast with independent labels before reporting accuracy.

Reproduce the comparison:

```powershell
uv run python scripts/compare_roster_reference.py results/manual_comparison/manual_reference.csv results/run_2_review/roster_observations.csv
```

The comparison script distinguishes missing rows, unknown fields, wrong values,
duplicate predictions and extra rows in reviewed frames. Original pipeline exports
remain unchanged. No model was trained or fine-tuned during this review.
